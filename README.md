# Hello from VERSE Brands

A simple welcome page for [VERSE Brands](https://versebrands.com/), a trusted online shopping destination in Bangladesh for imported coffee, groceries and lifestyle products.

**Live page:** https://versebrands.github.io/hello/ (after enabling GitHub Pages, see below)

## Run it

Open `index.html` in any browser. It is a single file with no dependencies.

## Publish with GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
